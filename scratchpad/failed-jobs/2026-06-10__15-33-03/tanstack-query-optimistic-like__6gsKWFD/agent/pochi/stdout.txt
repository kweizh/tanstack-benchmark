# TanStack Query Optimistic Updates ## Background Implement an optimistic update for a "liking" system using TanStack Query. Optimistic updates improve perceived performance by updating the UI immediately before the server responds. ## Requirements * Create a React application using TanStack Start and TanStack Query. * Implement a simple "Post" component that displays a post title and a "Like" button with a like count. * The "Like" button must trigger a mutation that updates the like count optimistically. * If the server request succeeds, the optimistic update is kept. * If the server request fails, the optimistic update must be rolled back to the previous state. * The app must run on port 4821. ## Implementation Hints * Use TanStack Query's `useMutation` with `onMutate`, `onError`, and `onSettled` callbacks to implement the optimistic update. * In `onMutate`, cancel any outgoing refetches for the query, snapshot the previous value, and optimistically update the cache using `queryClient.setQueryData`. * In `onError`, roll back the cache to the snapshotted value. * In `onSettled`, invalidate the query to ensure the client state is in sync with the server. * You can use TanStack Start's `createServerFn` or standard API routes to handle the backend logic. ## Acceptance Criteria * Project path: /home/user/project * Start command: npm run start * Port: 4821 * API Endpoints: * GET `/api/posts`: Returns an array of posts, e.g., `[{ "id": "1", "title": "Test Post", "likes": 0 }]`. * POST `/api/posts/:id/like`: Increments the like count. If the request body contains `{"fail": true}`, the endpoint must return a 500 status code without incrementing the like count in the database/memory. * UI Requirements: * The page at `/` must display the post title, current like count (identified by a `data-testid="like-count"` attribute), a "Like" button (`data-testid="like-button"`), and a "Simulate Failure" checkbox (`data-testid="simulate-failure"`). * Clicking "Like" when "Simulate Failure" is unchecked: The like count increases immediately. The server responds with 200 OK, and the like count remains increased. * Clicking "Like" when "Simulate Failure" is checked: The like count increases immediately (optimistic update). The server responds with a 500 error, and the like count reverts to its previous value.
