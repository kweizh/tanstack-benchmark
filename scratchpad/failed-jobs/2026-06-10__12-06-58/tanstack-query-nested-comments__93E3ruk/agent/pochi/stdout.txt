## What was built

### Backend (`server.js`)
- **GET `/api/comments`** → returns 200 with the full in-memory comments array
- **POST `/api/comments`** → sleeps exactly **1000 ms**, generates a UUID, appends the comment, and returns 201 with the new comment object
- Serves the pre-built React app from `dist/` at `http://localhost:5732/`
- Seeded with 4 comments (2 top-level + 2 nested replies) so the thread structure is visible immediately

### Frontend (`src/App.jsx`)
- **`useQuery`** fetches `/api/comments` and renders the nested thread
- **`useMutation`** drives the add-comment flow with the full three-phase optimistic update lifecycle:
  1. **`onMutate`** — cancels in-flight refetches, snapshots the previous cache, injects an optimistic comment (marked `_optimistic: true`) at the top of the list — **< 100 ms after submit**
  2. **`onError`** — rolls the cache back to the snapshot if the POST fails
  3. **`onSettled`** — always calls `invalidateQueries` so the server-issued `id` replaces the temporary optimistic one
- Optimistic comments are visually distinguished with an amber pulsing border, a "pending" tag, and a spinner
- A status bar below the form shows: *"Comment shown optimistically — waiting for server (1 s delay)…"* → *"Server confirmed"*
