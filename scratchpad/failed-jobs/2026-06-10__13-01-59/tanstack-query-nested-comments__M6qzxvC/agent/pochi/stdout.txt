## Key Implementation Details

**Backend (`server/index.js`):**
- In-memory comments array with 3 seed comments (1 nested reply)
- `GET /api/comments` → 200 with JSON array
- `POST /api/comments` → accepts `{text, parentId}`, waits exactly 1000ms via `setTimeout`, generates UUID `id`, returns 201
- Serves built React app from `client/dist/`

**Frontend Optimistic Update (`CommentForm.jsx`):**
- `useMutation` with `mutationFn: postComment`
- `onMutate`: cancels outgoing refetches, snapshots previous cache, optimistically inserts a comment with `_optimistic: true` flag
- `onError`: rolls back cache to previous snapshot
- `onSettled`: invalidates query to sync with server
- Optimistic comments render immediately (within 100ms) with dashed border + reduced opacity styling

**Nested Display (`CommentList.jsx`):**
- `buildTree()` transforms flat array into nested tree using `parentId` references
- Recursive `CommentItem` renders children with indentation and left border
